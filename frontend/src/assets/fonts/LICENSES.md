# Bundled fonts

| Files | Font | Licence |
|---|---|---|
| `Inter-*.woff`, `InterDisplay-*.woff` | Inter / Inter Display by Rasmus Andersson | SIL Open Font License 1.1 |
| `Pagella-*.woff` | TeX Gyre Pagella by GUST e-foundry | GUST Font License (LPPL 1.3c based) |

All files are Latin subsets made with `pyftsubset` and converted to WOFF. The CSS family name for Pagella is `PartPilot Serif`; the font's internal names are unchanged.
